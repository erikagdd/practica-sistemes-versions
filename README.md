# Pràctica 1 - Sistemes de control de versions

En aquesta pràctica he creat una pàgina web senzilla per a mostrar alguns exemples amb HTML i JavaScript.  

Per a organitzar el treball he fet servir branques diferetns (features, release i hotfix) i després les he ajuntat en `develop` i `main`.  

- En la branca "develop" està el projecte web amb l’arxiu "index.html".  
- En la branca "gh-pages" està la documentació de la pràctica, que també es pot vore en GitHub Pages.  

Documentació completa en GitHub
