Creació del repositori i preparació

 

Primer he creat un repositori buit a GitHub amb el nom practica-sistemes-versions en el meu usuari erikagdd. Després l’he clonat i he creat la branca develop per començar el desenvolupament.

git clone https://github.com/erikagdd/practica-sistemes-versions.git

cd practica-sistemes-versions

git checkout -b develop

git push -u origin develop

(Com no hem deixava fer el push, he creat un fitxer primer i ho he intentat de nou)

 

Usuari 1: Estructura inicial

 

L’usuari 1 crea la branca feature/estructura amb git checkout -b feature/estructura develop

i implementa l’estructura bàsica de la pàgina amb el boilerplate, incloent capçalera, barra de navegació amb Home, cos amb una descripció breu i el footer.

(com em donava error, he tingut que crear primer el arxiu index.html)

Al crear index.html i introducir code, sobri el visual studio amb el fitxer. Aci el usuari 1 crea l’estructura básica de la página:

Després fusiona la branca en develop.

git checkout -b feature/estructura develop

git add .

git commit -m "Usuari1: estructura inicial (capçalera, nav, footer)"

i açò per a fer el develop:

git checkout develop

git merge feature/estructura

git branch -d feature/estructura

git push

Torne a la branca develop, fusione el que hi havia a estructura amg el merge i borre estructura.

 Release v1.0

 

Quan ja hem tingut totes les funcionalitats, l’usuari 3 ha creat una branca de release, l’ha preparada i després l’ha fusionada en main i en develop. També hem creat l’etiqueta v1.0.

 

git checkout -b release/1.0 develop

git add .

git commit -m "Usuari3: preparar release 1.0"

git checkout main

Ací m’ha donat error, per això he creat la branca principal main a partir d’aquesta release, perquè fins aquest moment només havia treballat amb develop. Finalment he fusionat la release tant en main com en develop, he eliminat la branca de release i he creat l’etiqueta v1.0 .

git merge release/1.0

git checkout develop

git merge release/1.0

git branch -d release/1.0

git tag v1.0

git push --all

git push --tags

 

Hotfix milloresV_1_0

 

L’usuari 1 ha vist una millora a fer en la secció de contingut i ha creat un hotfix. Després l’ha fusionat en main i en develop, ha esborrat la branca temporal i ha creat l’etiqueta v1.0.1 per a la nova versió.

git checkout main

git checkout -b hotfix/milloresV_1_0

git add .

git commit -m "Usuari1: millores menors en secció de contingut"

git checkout main

git merge hotfix/milloresV_1_0

git checkout develop

git merge hotfix/milloresV_1_0

git branch -d hotfix/milloresV_1_0

git tag v1.0.1

git push --all

git push –tags

Amb estos passos he publica la versió v1.0.1 que inclou la millora, mantenint al dia la branca principal i la de desenvolupament.

 

Documentació en gh-pages

 

Per a la documentació hem creat una branca gh-pages amb una carpeta docs/ que conté un index.html amb la teoria de git, la descripció del procés i les captures dels passos realitzats.

git checkout --orphan gh-pages

git rm -rf .

mkdir docs

git add docs

git commit -m "Doc: publicació documentació en gh-pages"

git push -u origin gh-pages

 

Després hem activat GitHub Pages des de la configuració del repositori, triant la branca gh-pages.

Torne a a la branca, gh-pages, mire que dins está docs i ahí afegixc el index.html

Quan ja tenia quasi tota la pràctica feta, em faltava un pas: publicar la documentació en GitHub Pages. Al principi em donava error 404 perquè no trobava bé l’arxiu index.html. Després em vaig donar conter que el bo estava amb un altre nom (index (2).html) i dins de la carpeta equivocada. També vaig veure que GitHub Pages s’havia de configurar perquè apuntara a la carpeta docs/. Una vegada vaig renombrar l’arxiu com index.html, afegir la carpeta amb les imatges i actualitzar la configuració, ja es va vore tota la memòria correctament a la URL de GitHub Pages.

 

 

Projecte i col·laborador

Per acabar la pràctica he creat un Project a GitHub de tipus tauler (kanban). He deixat les columnes Todo, In progress i Done, i dins de la columna Done he anat posant targetes amb cadascuna de les branques que he fet: feature/estructura, feature/contingutHTML, feature/atributsHTML, feature/estilsCSS, release/1.0 i hotfix/milloresV_1_0. D’aquesta manera queda reflectit visualment el procés de treball que he seguit amb les diferents branques i versions.

 

A més, també he afegit al repositori com a col·laborador l’usuari antoni-gimenez, tal com es demanava a l’enunciat.

Quan estaba fent comprobacions, vaig tindre un moment de dubte perquè no trobava l’index.html del projecte web. Al final vaig veure que no estava en la branca gh-pages, sinó en la branca develop. Quan vaig canviar a eixa branca, ja vaig trobar l’arxiu i el vaig poder obrir al navegador per comprovar que funcionava la web.

Finalment, he afegit un README.md al repositori amb una explicació senzilla de què tracta la pràctica i un enllaç directe a la documentació publicada. Així, el professor pot entrar al repositori i veure de seguida la informació bàsica i l’enllaç a la memòria completa.
